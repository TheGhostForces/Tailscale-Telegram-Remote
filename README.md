# Remote Control: удалённое управление личными компьютерами

Личная система удалённого управления ПК (Windows) и ноутбуком (Debian/GNOME) с телефона и друг с другом, независимо от сети. Состоит из готовых компонентов и небольшой своей обвязки.

```
Телефон / ПК / ноутбук ──┐
                         │  Tailscale (WireGuard), ACL
VPS: Telegram-бот ───────┤──► агент :8765 на ПК и ноутбуке
VPS: RustDesk hbbs/hbbr  │    (слушает только адрес Tailscale, подпись HMAC)
                         │
Бот ──UDP magic packet──► роутер (проброс UDP + ARP-привязка) ──► спящий компьютер
```

## Возможности
- Удалённый рабочий стол: RustDesk с собственным сервером.
- Агент: статус, сон, блокировка, перезагрузка, выключение, скриншот, запуск команд из белого списка, Wake-on-LAN.
- Telegram-бот: ответы только владельцу, опасные действия через кнопку и TOTP, уведомления о выходе устройства в сеть и о попытках доступа.
- Пробуждение спящего компьютера через проброс UDP-порта на роутере.

## Структура
| Папка | Содержимое |
|---|---|
| `agent/` | агент (FastAPI), установщики для Windows и Debian |
| `bot/` | Telegram-бот (aiogram), установщик для VPS |
| `server/` | RustDesk (docker compose), ACL Tailscale, брандмауэр VPS |
| `docs/` | [установка](docs/SETUP.md), [приёмка](docs/ACCEPTANCE.md), [разбор проблем](docs/TROUBLESHOOTING.md) |

## Требования
- Аккаунт Tailscale (с 2FA), VPS с Debian/Ubuntu и белым IP, Telegram-бот (@BotFather).
- Python 3.10+ на каждом устройстве и на VPS; Docker на VPS для RustDesk.
- Для Wake-on-LAN: роутер с проброском UDP-порта и ARP-привязкой, белый IP или DDNS.

## Быстрый старт
Подробно: [docs/SETUP.md](docs/SETUP.md).
1. Tailscale на всех устройствах; ACL из `server/tailscale-acl.json`.
2. RustDesk-сервер: `server/docker-compose.yml`, клиенты на ваш сервер.
3. Агент: `agent/install-windows.ps1` / `agent/install-linux.sh`.
4. Бот: `bot/install-vps.sh`, заполнить `.env` и `config.yaml` по образцам.

## Конфигурация и секреты
В репозитории только образцы: `config.example.yaml` (агент и бот) и `bot/.env.example`. Реальные `config.yaml` и `.env` создаются на устройствах и **не коммитятся** (см. `.gitignore`).

| Секрет | Где живёт |
|---|---|
| `AGENT_SECRET` | `.env` агента на устройстве; тот же в `.env` бота как `PC_SECRET` / `LAPTOP_SECRET` |
| `BOT_TOKEN`, `OWNER_ID`, `TOTP_SECRET` | `.env` бота на VPS |
| ключ RustDesk-сервера `id_ed25519` | `server/data/` на VPS |

## Безопасность
- Агент слушает только адрес Tailscale, проверяет IP клиента (100.64.0.0/10), HMAC-подпись каждого запроса, окно времени (30 с), повтор nonce и частоту запросов.
- Бот отвечает только `OWNER_ID`; `sleep`, `reboot`, `shutdown` и `/run` требуют кнопку и одноразовый TOTP-код.
- `/run` выполняет только команды из `commands` в `config.yaml` агента, без shell.
- Агент и бот управляют питанием компьютеров. Используйте на свой риск, храните секреты вне репозитория, держите ПО обновлённым.

## Ограничения
- Пока в системе никто не вошёл, агент не работает (RustDesk как служба доступен).
- Скриншот на заблокированном экране Windows и в сессии Wayland может не получиться.
- Ноутбук будится только дома (по кабелю надёжнее Wi-Fi).
- Docker обходит ufw для опубликованных портов контейнеров.
