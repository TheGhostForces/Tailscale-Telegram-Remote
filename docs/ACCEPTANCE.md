# Приёмка

| # | Критерий | Как проверить |
|---|---|---|
| 1 | Рабочий стол любого устройства с другого из разных сетей | Ноутбук на раздаче телефона → ПК, и обратно; телефон → оба |
| 2 | Посторонний не подключится | С внешнего хоста: `nmap -p- <IP VPS>` → открыты только SSH и 21115–21119 (и UDP 21116); `nmap -sU -p 40009 <IP роутера>` → только этот порт; `curl http://<tailscale-IP>:8765/status` из внешней сети недоступен; из Tailscale без подписи → 401 |
| 3 | Бот слушает только ваш ID | Написать боту с другого аккаунта: молчание + уведомление вам; `/reboot pc` без TOTP не выполняется |
| 4 | Сон → пробуждение | `/sleep pc`, затем `/wake pc` из мобильной сети: «проснулся» |
| 5 | Автозапуск после перезагрузки | Перезагрузить оба устройства: агент отвечает на `/devices`, RustDesk подключается |
| 6 | Ресурсы агента | Диспетчер задач / `htop`: < 2 % CPU, < 100 МБ RAM в простое |
| 7 | Добавление и удаление устройств | `rcctl add` → устройство в `/devices` бота за несколько секунд; `rcctl remove` → исчезает; телефон из `add-client` в боте не виден |
| 8 | Интерфейс бота | Кнопки внизу работают; навигация правит одно сообщение; введённый TOTP-код исчезает из чата; «Magic packet…» заменяется на «проснулся»; таймер срабатывает и присылает отдельное сообщение |
