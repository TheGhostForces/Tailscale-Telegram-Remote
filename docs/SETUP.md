# Пошаговая установка

Порядок соответствует этапам ТЗ. После каждого этапа есть проверка — не переходите дальше, пока она не проходит.

## Этап 1. Приватная сеть (Tailscale)

1. Создайте аккаунт Tailscale через провайдера входа с **включённой 2FA**.
2. Установите Tailscale на ПК, ноутбук, телефон и VPS: `tailscale up`.
3. VPS подключите с тегом: в Admin console → Settings → Keys создайте auth key (с тегом `tag:bot`), затем на VPS:
   `sudo tailscale up --auth-key=tskey-... --advertise-tags=tag:bot`
   (теги у устройства задаёт владелец через `tagOwners`, ключ у тегированных устройств по умолчанию не истекает).
4. Access controls → вставьте содержимое `server/tailscale-acl.json` (файл в формате HuJSON, комментарии допустимы; проверьте политику во встроенном редакторе).
5. Запишите Tailscale-адреса (`tailscale ip -4`) ПК и ноутбука — они пойдут в `bot/config.yaml`.

**Проверка:** с телефона `ping` до адреса ПК и ноутбука; с VPS `tailscale ping <имя ПК>` работает.

## Этап 2. RustDesk (self-hosted)

На VPS:
```bash
sudo apt install -y docker.io docker-compose-v2
cd server && RUSTDESK_HOST=ваш.домен.или.IP docker compose up -d
cat data/id_ed25519.pub        # публичный ключ сервера
sudo SSH_PORT=22 bash vps-firewall.sh   # после проверки входа по SSH-ключу
```
(при желании примените `sshd-hardening.conf`: скопировать в `/etc/ssh/sshd_config.d/`, `systemctl reload ssh`).

На каждом клиенте RustDesk (ПК, ноутбук, телефон): Настройки → Сеть → Сервер ID/ретрансляции = ваш хост, **Key** = содержимое `id_ed25519.pub`.

- **Windows:** в RustDesk нажмите «Установить» (даёт работу на экране блокировки и UAC), Настройки → Безопасность: задайте **длинный постоянный пароль**, отключите «Включить прямой IP-доступ».
- **Debian:** поставьте `.deb` с GitHub RustDesk, тот же пароль и настройки. Рабочий стол должен быть на Xorg: на экране входа (шестерёнка) выберите **«GNOME on Xorg»**. Если такого пункта нет в вашей версии Debian (на вашей Debian 13 проверьте), запасной вариант — GNOME Remote Desktop (RDP) поверх Tailscale. Для доступа без вас включите автоматический вход пользователя.

**Проверка:** подключение ПК → ноутбук и обратно, телефон → оба, с разных сетей (например, ноутбук на раздаче с телефона).

## Этап 3. Агент

Скопируйте папку `agent/` на устройство. Заполните `config.yaml` (скопируйте `config.example.yaml`): MAC-адреса обоих устройств (`ipconfig /all` / `ip link`), широковещательный адрес LAN (обычно `192.168.0.255` для TP-Link) и при желании команды для `/run`.

**Windows (ПК)** — PowerShell от администратора:
```powershell
cd agent
powershell -ExecutionPolicy Bypass -File .\install-windows.ps1 -ConfigureWol
```
Скрипт покажет `AGENT_SECRET` — сохраните как `PC_SECRET`. Агент запускается задачей «при входе» в сессии пользователя (иначе скриншоты невозможны из-за Session 0). Чтобы он стартовал после перезагрузки без вас, включите автовход Windows (`netplwiz`) — либо учтите, что до входа в систему агент не работает.
Флаг `-ConfigureWol` отключает быстрый запуск и гибернацию (иначе «сон» превратится в гибернацию, а WoL из неё работает хуже) и включает Wake on Magic Packet.

**Debian (ноутбук)** — под обычным пользователем:
```bash
cd agent
bash install-linux.sh --wol enp3s0      # имя проводного интерфейса: ip link
```
Секрет → `LAPTOP_SECRET`. Сервис работает как `systemd --user` в графической сессии.

**Проверка** (с VPS или телефона-терминала; `bot/` нужен для подписи):
```bash
cd bot && python3 - <<'PY'
import httpx
from signing import make_headers
h = make_headers("<AGENT_SECRET>", "GET", "/status")
print(httpx.get("http://100.x.y.z:8765/status", headers=h).json())
PY
```
Запрос без подписи/с чужим IP должен давать 401/403.

## Этап 4. Telegram-бот

1. @BotFather → `/newbot` → токен. Свой числовой ID — у @userinfobot.
2. `cd bot && python3 gen_totp.py` — добавьте `TOTP_SECRET` в приложение-аутентификатор.
3. Заполните `bot/.env` и `bot/config.yaml` (адреса Tailscale, MAC, `secret_env`).
4. На VPS: `sudo bash install-vps.sh`, затем `sudo systemctl restart rc-bot && journalctl -u rc-bot -f`.

**Проверка:** `/devices` показывает оба устройства; `/lock pc` работает сразу; `/reboot pc` просит кнопку и TOTP; с чужого аккаунта бот молчит, а вам приходит уведомление о попытке.

## Этап 5. Wake-on-LAN через роутер (TP-Link Archer AX12)

Вы уже проверили этот способ. Для воспроизводимости, что нужно на роутере для **каждого** устройства (названия пунктов зависят от прошивки):
1. Резервирование DHCP: IP ↔ MAC устройства (Address Reservation).
2. Статическая ARP-привязка этого IP к MAC (IP & MAC Binding) — без неё роутер «забывает» спящее устройство.
3. Виртуальный сервер: UDP, внешний порт → внутренний IP устройства, порт 9. Рекомендуется разные нестандартные внешние порты: `40009` → ПК, `40010` → ноутбук (они указываются в `wake.port` бота).
4. `wake.host` в `bot/config.yaml` — белый IP или DDNS-имя роутера.

На ПК: WoL в BIOS/UEFI (Wake on LAN / PCIe wake, ErP выключить). Ноутбук будится только при подключении к домашней сети (лучше по кабелю); из раздачи телефона WoL невозможен — бот сообщит, что устройство не появилось.

**Проверка:** `/sleep pc` → `/wake pc` из мобильной сети: бот пишет «проснулся».

## Этап 6. Безопасность и документация

- Включите 2FA в Tailscale, ACL применён, ключи устройств имеют срок жизни.
- На VPS работает `vps-firewall.sh`; SSH только по ключам.
- Логи: `agent.log` на устройствах (рядом с агентом), `bot.log` на VPS (`/opt/rc-bot`). Файлы `.env` — права 600, в git не добавлять.
- Обновления: ОС, Tailscale, RustDesk, `pip install -U -r requirements.txt`.
- Новое устройство: Tailscale + RustDesk + агент (`install-*`), затем запись в `bot/config.yaml` и новый `*_SECRET` в `.env` бота.

## Известные ограничения

- Пока на устройстве никто не вошёл в систему, агент не работает (RustDesk как служба Windows при этом доступен). Лечится автовходом.
- Скриншот на заблокированном экране Windows и в Wayland-сессии GNOME может не получиться; используйте Xorg.
- `/sleep` на Windows требует отключённой гибернации (делает `-ConfigureWol`).
- Открытый UDP-порт на роутере принимает только magic packet; нестандартный порт снижает шум сканеров.
